# Version Details

This page documents each FlexCloud release —
the Ubuntu / ROS 2 / Python combination the wheels were built against, plus the
CLI help output of both executables captured directly from the container image.

- **Latest** — rolling snapshot, rebuilt on every push to `main` from
  `ghcr.io/tumftm/flexcloud:latest`.
- **`vX.Y.Z`** — frozen at release time from `ghcr.io/tumftm/flexcloud:vX.Y.Z`.
  These pages are never regenerated, so they remain accurate even as the docs
  site evolves.
